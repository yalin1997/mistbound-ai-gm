## 聚焦自查結論

已確認：模型不能指定骰點或直接改資料；角色與房間請求需驗證權限；資料提交先於事件推送；重試有去重；不持鎖等待模型；檢定／結果不因重新整理重置；沒有 AI key 時畫面明確標為規則模式；內容不符版本時不擅自套用規則。資料庫及登入資料未納入 Git。

保留限制：內容只有兩章固定模板，職業技能尚未差異化效果；自由意圖被限制在既有能力；AI 旁白的語意一致性仍需真實模型評測；沒有正式客服／密碼重設、分散式房間協調與壓力測試；離線成員席位不會被永久移除。這些限制已列於 README，沒有以測試通過宣稱解決。

## 真實模型驗證清單

1. 在環境秘密設定配置 OPENAI_API_KEY，在非秘密設定配置 OPENAI_BASE_URL、OPENAI_MODEL，允許對應 API 網域。金鑰不可貼入聊天或寫進來源。
2. 重新啟動，確認 health 回傳 live（只代表配置存在）。使用真實模型完成單人與合作冒險；保留不含個資的測試輸入、模型／提示版本、結果與 usage／durationMs。
3. 使用至少 50 個人工標記案例，含合理創意、模糊目標、世界觀違規及提示注入。分別檢查接受／拒絕正確性及敘事是否與正式結果衝突，不以固定關鍵字模式代替。
4. 測試供應商 timeout／429、錯誤格式及預算耗盡，不重複擲骰與扣資源；量測整個行動流程與單次模型延遲，記錄單人／合作各自費用。
5. 指定遠端 repo 後建立 PR 並實際跑 CI；異地遊玩需提供 HTTPS／WSS 環境並由不同網路玩家連線測試。
